Put your song in this folder named:

  song.mp3

(or change js/config.js -> song.src to match a different filename).

The music control in the bottom-right corner stays off until she taps
it — nothing autoplays. If no file is present, the button simply does
nothing when tapped, so it's safe to leave this empty for now.

Delete this README before deploying if you'd like a clean folder.
